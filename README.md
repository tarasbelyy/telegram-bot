# Телеграм бот @ollieok_chatbot


## Описание
Телеграм бот на основе API https://github.com/tarasbelyy/django-chatbot-ai-api


## Инструкция 
Для запуска бота в диалоговом окне введите /start
```
@ollieok_chatbot
```

## Функциональность
- поддерживаются просмотр списка ботов с описаниеми и запуск бота
- выбор бота и опций сценария диалога осуществляется через inline-кнопки
- в случае ошибки выводится соответствующее сообщение

## Требования
Основные внешние библиотеки и фреймворки для Python, используемые в проекте: 
- aiogram версии 3.30.0
- requests версии 2.34.2

Приложение развертывается в Docker.
